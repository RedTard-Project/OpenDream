# tgstation-RPG на OpenDream: что сделано, зачем и что осталось

Состояние на 24.11.2026. Ветка OpenDream `tgstation-rpg`, срезана от upstream/master `c03f7465`. **Изменения не закоммичены**: 31 изменённый файл (+1201 / −251) и 3 новых теста. `master` не тронут.

## Где что лежит

| Путь | Что это |
|---|---|
| `C:\RedTardProject\OpenDream` | движок: компилятор, сервер, клиент |
| `C:\RedTardProject\tgstation-RPG` | исходники игры, ветка `new-release`. Правки модуля под OpenDream уже в коммите `0adda3fb280` |
| `C:\RedTardProject\tgstation-RPG-OpenDream` | папка «релиза»: копия игры, скрипты сборки и запуска |

Папка релиза не самостоятельная: берёт движок из `..\OpenDream\bin`.

## Как собрать и запустить

Из `C:\RedTardProject\tgstation-RPG-OpenDream`:

| Команда | Действие |
|---|---|
| `BUILD_OPENDREAM.ps1` | взять свежие исходники из `tgstation-RPG` и скомпилировать `tgstation_od.json` (~80 с) |
| `BUILD_OPENDREAM.ps1 -Engine` | то же и пересобрать движок. Перед этим закрыть клиент и сервер, иначе файлы заняты |
| `BUILD_OPENDREAM.ps1 -NoSync` | не брать исходники из репозитория |
| `OD_SERVER.cmd [карта]` | сервер, только localhost. Без аргумента — Rockhill |
| `OD_CLIENT.cmd [имя]` | клиент |

Нужен .NET SDK 10 (стоит 10.0.404, через winget). Тесты движка:

```powershell
dotnet test Content.Tests/Content.Tests.csproj -c Release
```

Карта готова, когда в консоли сервера появится `Initializations complete`. До начала раунда вход закрыт, лобби показывает таймер.

Сообщение компилятора `Compiler arg 'define' requires a value, skipping` безвредно: разборщик добавляет аргумент дважды, сам define применяется.

## Что сделано и зачем

### Компилятор

| Что | Зачем |
|---|---|
| `DMCodeTree*.cs`: статики процедур, которые инициализируются вызовом процедуры, выполняются в порядке объявления (`GlobalInit`, `EmitGlobalInits`) | иначе `world.Genesis()` tg выполнялся позже статиков, которым нужен |
| `DMObject.cs`, `Expressions/Dereference.cs`, `Binary.cs`: `путь::переменная_список` даёт копию списка | tg так собирает списки в типах |
| `DMObjectTree.cs`, `Filter.dm`: `/dm_filter` не является `/datum` | сигналы и проверки типов tg считали фильтр датумом |

### Сервер

| Что | Зачем |
|---|---|
| `DreamList.cs`, `DreamValue.cs`: `\|=`, `-`, `-=` между большими списками через хеши, быстрая запись по ключу, быстрый поиск объекта | главное ускорение загрузки карты |
| `EntryPoint.cs`: инвариантная культура | русская локаль писала «0,5» вместо «0.5» и ломала winset и числа |
| `Objects/DreamIcon.cs`: `Blend` со смещением и границами, `Shift`/`Turn` относительно кадра | иконки собирались со сдвигом |
| `DreamProcNativeRoot.cs`: `fcopy` отсутствующего файла возвращает 0 | раньше был runtime |

### Интерфейс и ввод клиента

| Что | Зачем |
|---|---|
| `ParamsHelpers.cs`, `DreamInterfaceManager.cs`: переписан разбор winset (кавычки, вложенные значения, команды из нескольких строк) | upstream `#2753` сломал макросы: не работали ходьба и клавиши |
| `InterfaceMacro.cs`: `Any`, `Any+UP`, разделители, названия клавиш как в BYOND | ввод tg построен на макросах `Any` |
| `ControlBrowser.cs`: `hubStorage` для `browser-options=+byondstorage` | чат и настройки tgui |
| `ControlWindow.cs`, `InterfaceControl.cs`: якоря в виртуальных пикселях, удаление через `parent=`, размер 0 | панели разъезжались при масштабе экрана 150 % |
| `ControlMap.cs`, `ScreenLocation.cs`, `ViewRange.cs`, `ClientScreenOverlaySystem.cs`: границы карты, якоря `SCREEN_*`, повторы, отрицательные координаты | HUD Рогатауна лежит за пределами игрового поля |
| `MouseInputSystem.cs`: координаты мыши с учётом границ | клики по HUD попадали мимо |

### Отрисовка и FPS

| Что | Зачем |
|---|---|
| `DreamViewOverlay.cs`, `DreamPlane.cs`: пустые и никому не нужные плоскости не рисуются | у tg 216 плоскостей на мульти-z, рисуется ~65 |
| `DreamPlane.cs`: постоянный render target у мастеров плоскостей, учитывается их alpha | создавались заново каждый кадр |
| `DreamViewOverlay.cs`, `DreamIcon.cs`: кэш шейдеров цвета | шейдер копировался на каждый спрайт |
| `DreamResourceManager.cs`, `DMIResource.cs`: DMI декодируются в фоне, загрузка в видеопамять до 4 мс за кадр | большие DMI давали рывки до 100+ мс |

### Игра (уже закоммичено в tgstation-RPG)

- `crafting/casting.dm`: дублирующийся `parent_type`.
- `economy/debts_panel.dm`, `funds.dm`, `navigator.dm`: скобки вокруг `in`. Это ошибки и под BYOND.
- `lighting/subsystem.dm`: `#ifdef OPENDREAM`, потому что `load_ext` в OpenDream нет.

## Что проверено

- Тесты движка: 692 из 692, включая три новых.
- Полная сборка движка и игры без ошибок.
- Последний запуск (24.11.2026, после удаления отладки): карта загрузилась за 124 с, лобби, вход Assistant, HUD, свет, конус обзора, ходьба, чат и панель статуса работают. NRE на сервере нет.

## Что надо сделать

### 1. Перетаскивание панелей, как в BYOND (просьба, не начато)

Причина найдена: `SplitterWidth` в `OpenDreamClient/Interface/Controls/UI/Splitter.cs` нигде не задаётся и равен 0, ручку нечем схватить. Нужно:

1. Задать ширину 4 пикселя: `fit_viewport` в tg (`code/modules/client/verbs/ooc.dm:363`) рассчитывает именно на неё.
2. Сохранять положение после перетаскивания. `ControlChild.UpdateElementDescriptor` ставит `SplitterPercentage` из описания при любом winset этого элемента и сбросит сдвиг.
3. Проверить, что перетаскивание вызывает `on-size` карты, и решить, должно ли `auto_fit_viewport` возвращать панель назад.
4. Проверить при масштабе экрана 150 % и над встроенным браузером.

### 3. Игра на Rockhill

- В позднем входе должности станции (Captain … Prisoner), средневековых ролей нет. Смотреть `modular_redtard/maps/era.dm` и `rockhill/jobs.dm`. С BYOND не сравнивалось.
- Assistant появляется то в гавани, то в CentCom: `get_latejoin_spawn_point` берёт случайную точку из `SSjob.latejoin_trackers`, а `CentCom_minimal.dmm` добавляет свою. Похоже на логику игры, с BYOND не сравнивалось.
- Нативный свет выключен: `rogue_light.dll` 32-битная, `load_ext` в OpenDream нет.

### 4. Производительность

- Декодирование OGG на главном потоке: рывок до 216 мс, код внутри RobustToolbox.
- Создание окна tgui ~73 мс.
- Скрытые вторичные окна всё равно копируются на экран, ~1,5 мс за кадр. Cvar `display.thread_unlock_before_swap` рискованный.
- Замедление времени сервера при входе игроков, пики до 120 %.

- Один раз при самом первом запуске не загрузились 6 DMI, повторить не удалось.

## Осторожно

- **Сервер только на localhost.** ImageSharp 3.1.12 имеет известные уязвимости, апстрим их заглушает. 3.2.0 требует коммерческой лицензии, обходить её нельзя.
- **Не раздавать папку релиза:** в ней копия `config/redtard_private`.
- Песочница клиента запрещает `символ + строка`: сборка пройдёт, но клиент не запустится. Проверять запуском.
- RobustToolbox — сабмодуль, не менять.
- В репозитории смешаны CRLF и LF, предупреждения git об этом безвредны.
- `Макет ХУДа Рогатауна.md` в корне к этой работе не относится, в коммит не брать.

## Как снимать профиль

Без установки программ: запустить процесс с переменными `DOTNET_EnableEventPipe=1` и `DOTNET_EventPipeOutputPath=файл.nettrace`, набор событий по умолчанию подходит. Файл открывается в PerfView или Visual Studio. Временные счётчики из кода убраны.
